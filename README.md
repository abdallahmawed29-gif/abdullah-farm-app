# زرع AI 🌱

منصة زراعية عربية MVP تجمع بيانات المحاصيل، الإرشاد الزراعي، واجهة تشخيص الصور، ومساعدًا زراعيًا قابلًا للربط بنماذج AI حقيقية.

## تشغيل المشروع

1. ثبّت Node.js.
2. افتح Terminal داخل مجلد المشروع.
3. شغّل:

```bash
npm install
npm run dev
```

4. افتح الرابط الذي يظهره Vite.

## رفعه على GitHub

أسهل طريقة: أنشئ Repository جديد باسم `zaraa-ai` ثم ارفع محتويات هذا المجلد.

أو باستخدام Git:

```bash
git init
git add .
git commit -m "Initial Zaraa AI MVP"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/zaraa-ai.git
git push -u origin main
```

## مهم قبل الإنتاج

النسخة الحالية MVP تعمل بواجهة وتجربة بيانات محلية. تشخيص المرض من الصورة والمحادثة الزراعية الحقيقية يحتاجان ربط Backend بنموذج AI/رؤية، مع قاعدة بيانات وWeather API.

**لا تضع مفاتيح API السرية داخل ملفات React أو GitHub.** استخدم Backend أو Serverless Functions ومتغيرات بيئة.

## بيانات المشروع

المشروع يتضمن مجموعات أولية من الخضروات والفاكهة والمحاصيل الحقلية والأعلاف والنباتات العطرية. يمكن نقل قاعدة المحاصيل لاحقًا إلى JSON/قاعدة بيانات وتوسيعها بمراحل النمو والتسميد والري والأمراض والملوحة.
